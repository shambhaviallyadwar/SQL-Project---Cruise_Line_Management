# 🚢 Cruise Line Management System — SQL Project

## 📌 Project Overview
The Cruise Line Management System is a database project developed using MySQL. It focuses on managing and analysing cruise line operations through structured data and SQL queries.

The project helps organise cruise-related information and practise database management and data analysis using real-world-style scenarios.

## 🎯 Project Objectives
- Manage cruise and passenger-related information.
- Organise cruise bookings and travel details.
- Analyse passenger and cruise data using SQL queries.
- Practise database relationships and data retrieval.
- Develop problem-solving skills through SQL-based analysis.

## 🛠️ Tools & Technologies
- **Database:** MySQL
- **SQL Editor:** MySQL Workbench
- **Version Control:** GitHub

## 📚 SQL Concepts Used
- Database and table creation (DDL)
- Data insertion and modification (DML)
- SELECT statements and filtering
- Sorting and grouping
- Aggregate functions such as COUNT, SUM, AVG, MIN and MAX
- Joins
- Subqueries
- Constraints and keys
- Views and other SQL concepts as applicable

## 📊 Project Tasks
This project includes SQL queries designed to practise cruise line database management and analysis, such as:
- Retrieving cruise and passenger details.
- Analysing bookings and passenger information.
- Summarising data using aggregate functions.
- Combining related tables using joins.
- Answering business-related questions using SQL.

## 💡 Key Learning Outcomes
- Understanding relational database design.
- Writing SQL queries to retrieve and analyse data.
- Working with primary keys and foreign keys.
- Understanding relationships between multiple tables.
- Applying SQL concepts to a practical management scenario.
